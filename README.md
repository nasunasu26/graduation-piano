## キラクナピアノ | ログインなしで弾ける無料ピアノアプリ
RUNTEQ 卒業制作用 Webアプリ

## サービス概要
本サービスは、ブラウザ上で気軽にピアノ演奏を楽しめるWebアプリです。
「自由演奏モード」では、画面上の鍵盤をクリックすることで音を鳴らし、自由に演奏できます。
また、メロディーの一部を気軽に覚えられる「曲を少し覚えるモード」も備えています。

ログインやインストール不要で、気軽にピアノに触れられる体験を目指しています。

## このサービスへの思い・作りたい理由
小さい頃からピアノに憧れはあったものの、ピアノ本体の価格やレッスン代の問題から気軽に始めることが難しいと感じていました。

また、継続して練習しなければならないプレッシャーもあり、
もっと「気軽に触れられるピアノ体験があればいい」と考え、本アプリを制作しました。

## ユーザー層について
- ピアノや音楽が好きだが初心者の人
- 子ども向けの音遊びアプリを探している人
- ゲーム感覚で音感や記憶力を鍛えたい人

## サービスの利用イメージ
アクセスするとすぐにピアノ画面へ進め、「自由演奏モード」で好きなように音を鳴らせます。

「曲を少し覚えるモード」では、著作権切れのクラシック曲を題材に、
メロディーを覚えながら演奏に挑戦できます。

## サービスの差別化ポイント
- 練習や継続を前提としない、気軽に遊べるピアノ体験
- 専門知識がなくても直感的に操作可能
- ログイン不要ですぐに演奏を始められる

## 現在のデータ管理について
楽曲データは songs テーブルで管理しています。

演奏履歴やお気に入り情報は、現在 localStorage を利用して管理しています。

将来的には、任意のユーザー登録機能の追加に伴い、
これらの情報もテーブルで管理する予定です。

## テーブル詳細

### songs テーブル
- id : bigint（PK）
- title : string（曲名）
- notes : text（音階データ）
- created_at : datetime
- updated_at : datetime

## 現在実装済みの機能

  - localStorage を利用した初回表示制御

- 自由演奏モード

- localStorage を利用した演奏履歴表示機能
